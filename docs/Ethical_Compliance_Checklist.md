# Ethical use and review checklist

Before using a generated paper:

- Confirm the source materials are authorized for use and upload.
- If hosted LLM mode is enabled, confirm the provider and data-retention terms are suitable. Notes are sent to that API.
- Keep personal and sensitive information out of the source notes unless there is explicit authority and appropriate safeguards.
- Review each question against the intended learning outcomes and syllabus.
- Check facts, answer keys, marks, clarity, accessibility, cultural bias, and age appropriateness.
- Confirm distractors have one defensible correct answer; remove ambiguous items.
- Disclose AI assistance as required by the institution and retain educator responsibility for final use.
- Do not use generated content as a sole basis for high-stakes decisions or as professional medical/legal advice.

The supplied dataset is synthetic metadata and its source license is not provided. This project keeps it for descriptive analysis only and does not use it as training material. The learner should confirm license and attribution requirements before external redistribution.
